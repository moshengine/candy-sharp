# Candy Unity

Unity editor tools and runtime utilities (`com.moshengine.candy-unity`).

## Install

```json
"com.moshengine.candy-unity": "https://github.com/moshengine/candy-sharp.git?path=/candy-unity#v0.1.0"
```

Local iteration: `Tools → Candy → Package Management → Toggle to Local` (expects this repo as a sibling of the Unity project root).

## Extension points

- `Runtime/` — pooling, HTTP, StreamingAssets, attributes, math helpers
- `Editor/` — validators, package toggler, tile brushes, project structure
